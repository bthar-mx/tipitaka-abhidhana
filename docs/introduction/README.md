# Vol. 1 introduction (နိဒါန်း): transcription and translation

The introduction to vol. 1 (1964) is the only account of how the dictionary was planned and made.
This folder holds a clean Burmese transcription of it, made from the page images, and translations
into English and Spanish, each made from the Burmese.

## Method

1. **Transcribe** each page from the image (130 dpi renders of `pdfs/01.pdf`). The OCR in
   `ocr/01/pages/` is too noisy for prose and is used only as a cross-check. Uncertain readings are
   marked ⟨?⟩.
2. **Translate** the transcription into English and into Spanish separately. Spanish is translated
   from the Burmese, not relayed through English. Pāḷi technical terms are kept in Pāḷi, glossed at
   first use, and follow the IEBH glossary once it has them.
3. **Status** per part: `drafted` (Claude) → `reviewed` (the editor) → `corrected`. Nothing drafted is a
   reading until reviewed.

One file per chapter, each with three sections: Burmese, English, Spanish, then notes for review.
