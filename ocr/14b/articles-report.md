## What these figures mean

As for the scanned books (`ocr/03/articles-report.md`), except that the page text is the PDF's own
text layer converted from WinInnwa to Unicode, not OCR. The misses are therefore print against
index, not reading: this book's index was typed separately and has more typos (brief §25). Every
row is `status: "ocr"` all the same (the conversion is not proofread).
